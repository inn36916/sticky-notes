# Windows 便携版

解压整个文件夹到可写目录，双击 StickyNotes.exe。无需安装 Node.js、npm 或 Python。不要直接在压缩包内运行。

便签数据在程序旁的 data 目录。升级前退出托盘中的程序，备份整个 data 目录，然后将它放到新版程序旁。程序会继续使用它；版本迁移还会保存升级前 JSON 快照。

完整备份必须同时包含 sticky-notes.json 和 attachments 目录。便签中心的「备份」按钮会创建配对副本；「数据目录」可打开所在位置。恢复时先退出程序，再把配对数据复制回 data。API 配置密钥使用当前 Windows 用户的系统加密，换机后需重新配置。

Markdown 导出可交换标题、正文、列表、任务、Mermaid 源码、图片与转换附件。资源目录必须和 Markdown 文件一起带走。纯文本仅保留文字与占位符。

单次提醒仅在程序运行时弹出系统通知；退出期间到期的提醒将在下次启动补发。Windows 禁用通知时，可从便签中心「已到期」查看。

全局划词默认关闭；可从便签中心主动开启。它会使用系统剪贴板，并需要可用的 Python 3。便签内划词、截图和内置 Mermaid 不需要 Python。

边缘卡组可在便签中心开启；Ctrl+Alt+G 或托盘菜单打开，Esc 收起。默认仍使用逐张贴边收纳。

本包未代码签名，Windows 可能显示来源提示。不要将程序目录放在只读目录。若系统策略禁止运行，请联系设备管理员。
