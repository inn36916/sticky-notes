# 当前机器实机验收（2026-11-21）

环境：Windows 11 家庭版 10.0.26200；一块内置显示器，1536×864 DIP，缩放 125%。用户要求改用当前屏幕验收，因此本轮不声称物理双屏或干净 Windows 虚拟机通过。

使用独立 user-data-dir 和合成文字/图片运行实际便携版，没有改已有便签库，也没有改 Windows 通知、隐私或显示设置。
